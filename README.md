# 大数据技术综合实验 - 期末大作业

广州商学院 信息工程与工程学院 2025-2026 学年第 2 学期

## 选题

待定（四选一）：
1. Spark 电商用户行为分析与推荐系统
2. Flink 微博实时大数据分析系统  
3. Spark 工业设备故障预测与能耗分析系统
4. Spark/Flink 股票市场实时分析与趋势预测系统

## 环境要求

- 数据分析：Linux 系统（Ubuntu/CentOS）
- 数据存储：HDFS / HBase / Hive / MySQL
- 数据处理：Spark / Flink
- 数据可视化：Jupyter / ECharts / Flask / Django
